# Plan: Add Icon Picker to Admin Amal Field Form

## Goal
Allow admins to choose an icon (from Font Awesome or Material Icons) when creating/editing an amal field. The icon is stored in Firestore and rendered in `AmalRow` instead of the current hardcoded switch on field ID.

## Step 5: Icon Rendering — `amal_row.dart`

Update `AmalFieldIcon` widget (or add a new helper) to check `field.iconName` and `field.iconSource` first. If set, resolve the icon dynamically. If not set, fall back to the existing hardcoded `amalFieldIconWidget(field.id)`.

Resolution logic:
```dart
IconData? resolveIconFromField(AmalField field) {
  if (field.iconName == null || field.iconSource == null) return null;
  if (field.iconSource == IconSource.material) {
    return _materialIconMap[field.iconName]; // lookup from a Map
  }
  return _fontAwesomeIconMap[field.iconName]; // lookup from a Map
}
```

Two static maps (`_materialIconMap`, `_fontAwesomeIconMap`) map string names to `IconData`. Unknown names fall back to the hardcoded switch.

The `AmalRow` widget already receives an `AmalField` — update its icon rendering to use the new resolution.

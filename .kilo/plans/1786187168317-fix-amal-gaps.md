## Task 1 — Create `tool/migrate_amal_fields.dart`

**File:** `tool/migrate_amal_fields.dart` (new)

Write a standalone Dart script (not part of the app build) that patches all existing `amal_fields` documents with the new gender-personalization attributes.

### Requirements
- Uses `cloud_firestore` package directly.
- Reads every document from `amal_fields` collection.
- Applies attribute mapping from the plan:
  - `genderVisibility: "all"` (all default fields)
  - `femaleDeprioritized: true` for `fard_salah`, `fard`, `takbir`; `false` for all others
  - `disableDuringSpecialTime: true` for `fard_salah`, `fard`, `takbir`, `quran`, `mulk`, `sunnah`, `post_azkar`; `false` for `morning_azkar`, `evening_azkar`, `miswak`
- Writes using Firestore batch updates (max 500 per batch).
- Prints progress: `Migrated X/Y fields`.
- Idempotent: safe to run multiple times (writes same values).

### Invocation
```bash
dart tool/migrate_amal_fields.dart
```

    required this.label,
    required this.displayScore,

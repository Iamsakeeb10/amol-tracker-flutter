# Add Top/Bottom Fade on Scroll to HomeScreen

## Context
The `HomeScrollBody` widget uses a `Column` with a fixed `HomeHeader` and an `Expanded` `CustomScrollView`. When the user scrolls, there's no visual indication of hidden content above or below. Adding gradient fade overlays at the top and bottom of the scroll area improves UX.

## Approach

Modify `lib/features/home/presentation/widgets/home_scroll_body.dart`:

1. **Convert `HomeScrollBody` from `ConsumerWidget` to `ConsumerStatefulWidget`** — needed to manage a `ScrollController` and scroll offset state.

2. **Add a `ScrollController`** — attach it to the `CustomScrollView`.

3. **Wrap `CustomScrollView` in a `NotificationListener<ScrollNotification>`** — listen for scroll updates and set `_showTopFade` / `_showBottomFade` booleans.

4. **Overlay gradient widgets** — use a `Stack` around the `CustomScrollView` with two `Positioned` gradient containers:
   - **Top fade**: appears when `scrollOffset > 0` — gradient from `AppColors.emeraldDeep` (opaque) to transparent, placed at the top of the scroll area.
   - **Bottom fade**: appears when not at the bottom of the scroll — gradient from transparent to `AppColors.emeraldDeep`, placed at the bottom.

5. **Animate the fade** — use `AnimatedOpacity` for smooth appear/disappear transitions.

## File to modify
- `lib/features/home/presentation/widgets/home_scroll_body.dart`

## Verification
- Run the app on a device/emulator
- Scroll the home screen content down → top fade should appear
- Scroll back to top → top fade should disappear
- Bottom fade should always be visible (content extends below viewport)
- No visual glitches or performance issues

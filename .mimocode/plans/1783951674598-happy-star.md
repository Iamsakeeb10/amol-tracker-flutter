# Plan: Individual Amal Field Edit Restriction by Creation Date

## Goal
When editing a past day, prevent editing **only** the amal fields that were created **after** that day. Other fields remain fully editable. This applies dynamically to any future field — no hardcoded field IDs.

**Example**: `fard_salah` was created on 1447-01-10. Editing 1447-01-05 → `fard_salah` is locked, all other fields editable. Editing 1447-01-12 → everything editable.

### 2. `lib/core/services/islamic_date_service.dart` — Add date comparison utility

Add a public static method (the existing `_parseHijriToGregorian` is private):

```dart
/// Whether [hijriDate] (YYYY-MM-DD) is on or after the day [createdAt].
/// Returns true if [createdAt] is null (legacy fields always editable).
static bool isHijriDateOnOrAfter(String hijriDate, DateTime? createdAt) {
  if (createdAt == null) return true;
  try {
    final parts = hijriDate.split('-');
    if (parts.length != 3) return true;
    final y = int.parse(parts[0]);
    final m = int.parse(parts[1]);
    final d = int.parse(parts[2]);
    final gregorianDay = HijriCalendar().hijriToGregorian(y, m, d);
    final fieldDay = DateTime(createdAt.year, createdAt.month, createdAt.day);
    return !gregorianDay.isBefore(fieldDay);
  } catch (_) {
    return true; // fail-open on parse error
  }
}
```

Uses the same `HijriCalendar().hijriToGregorian()` pattern at lines 276, 315, 453.

## Why This Works Dynamically

- Any future amal field added via admin UI will have `createdAt` in Firestore
- `fromMap()` parses it automatically
- `isHijriDateOnOrAfter()` checks it for every field in the edit screen
- No hardcoded field IDs — the logic is field-agnostic
- Fields without `createdAt` (legacy/fallback `kDefaultAmalFields`) stay always editable

---

## Edge Cases

| Scenario | Behavior |
|---|---|
| **Field has no `createdAt`** (legacy) | Always editable |
| **`kDefaultAmalFields` fallback** | No `createdAt` → always editable |
| **Hijri parse fails** | Fail-open → editable |
| **Field created same day as edited date** | Editable (same day = not before) |
| **Hive cache has old fields** | `fromMap()` → `null` → editable |
| **Backfill (no existing log)** | Locked fields stay at default (0/false) on save |

# Fix RenderFlex overflow in StreakBottomSheet _DayCard

## Problem
The `_DayCard` Column at line 593 overflows by 2.1px on bottom. The "অ্যাকাউন্টের আগে" (preAccount) text wraps to 2 lines at the narrow card width (~57.5px), making the Column taller than the available space.

## Fix (single file: `lib/features/home/presentation/widgets/streak_bottom_sheet.dart`)

### 1. Make status label single-line with ellipsis
Add `maxLines: 1` and `overflow: TextOverflow.ellipsis` to the status label `Text` widget at **line 620-629**:

```dart
Text(
  day.status == StreakDayStatus.completed
      ? '${day.score}'
      : _statusLabel(context),
  maxLines: 1,
  overflow: TextOverflow.ellipsis,
  style: AppTextStyles.pill(context).copyWith(
    fontSize: 9.sp,
    color: _iconColor(),
    fontWeight: FontWeight.w600,
  ),
),
```

### 2. Reduce vertical spacing slightly
Tighten the top/bottom padding inside the Column to give more breathing room:
- Line 597: `SizedBox(height: 3.h)` (was 4.h)
- Line 630: `SizedBox(height: 3.h)` (was 4.h)

This recovers ~2px total, comfortably clearing the 2.1px overflow.

# Fix: Badge celebration showing wrong "3-Day Streak" badge

## Problem
After submitting a daily log, the confetti/badge celebration animation pops up showing the "3-Day Streak" badge, but the actual streak is only 1 (correct on Home screen and StreakBottomSheet). The wrong badge is being awarded.

## Root Cause
`amal_provider.dart` `_syncClientSideBadgesAndFeed()` (line 594-598) awards streak badges using `resultingCurrentStreak`, which comes from `computeStreakResult()` (line 427-433). That function reads `user.currentStreak` from Firestore — a potentially stale value (e.g., 3). Meanwhile, `liveStreakProvider` recomputes the streak from actual logs and correctly returns 1.

So the badge eligibility check uses a stale Firestore value, incorrectly awarding the "3-Day Streak" badge.

## Fix

### Step 1: Make `isBackfilledLog` a shared public function
**File:** `lib/core/utils/streak_helper.dart`
- Add a public `isBackfilledLog(AmalLogModel log)` function (currently private in `history_provider.dart:259-270` and duplicated in `user_profile_screen.dart:848-859`)

**File:** `lib/providers/history_provider.dart`
- Replace private `_isBackfilledLog` (line 259-270) with import from `streak_helper.dart`

**File:** `lib/features/community/presentation/screens/user_profile_screen.dart`
- Replace private `_isBackfilledLog` (line 848-859) with import from `streak_helper.dart`

### Step 2: Recompute live streak for badge eligibility
**File:** `lib/providers/amal_provider.dart`
- In `_syncClientSideBadgesAndFeed()`, recompute the streak from actual Firestore logs (same logic as `liveStreakProvider`) before the badge loop
- Replace `resultingCurrentStreak` with `liveStreak` in the badge threshold check

```dart
// In _syncClientSideBadgesAndFeed, before the badge loop:
final recentLogs = await fs.getRecentLogs(user.uid, limit: 30);
final todayHijri = IslamicDateService.getCurrentIslamicDateStringSafe();
final loggedDates = <String>{
  for (final log in recentLogs)
    if (!isBackfilledLog(log)) log.hijriDate,
};
final frozenDates = <String>{
  if (user.streakFreezeDate.isNotEmpty) user.streakFreezeDate,
};
final liveStreak = computeStreakFromLogs(
  loggedDates: loggedDates,
  todayHijri: todayHijri,
  frozenDates: frozenDates,
);

for (final badge in kBadgeDefinitions) {
  if (badge.streakThreshold != null && liveStreak >= badge.streakThreshold!) {
    nextBadges.add(badge.id);
  }
}
```

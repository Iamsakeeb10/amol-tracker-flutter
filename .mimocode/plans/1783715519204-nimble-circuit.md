# Plan: Add Action Button with URL to Announcement Modal

## Goal
Allow admins to add an optional action button (with custom label + URL) to announcements. When a user taps the button, it opens the URL externally (e.g., Play Store link for app updates).

## Current State
- **Model**: `AnnouncementModel` has `title`, `message`, `arabicText`, `imageUrl`, `type`, `isActive`, `startsAt`, `expiresAt`, `showOnce`, `createdAt` — no action button fields.
- **Modal UI** (`announcement_modal.dart`): Shows content + a single "Understood" dismiss button. No action button.
- **Admin form** (`admin_announcement_form_screen.dart`): Fields for title, message, arabic text, image URL, toggles, dates. No action button fields.
- **Firestore mapper** (`admin_announcement_helpers.dart`): `announcementToFirestoreMap()` maps form fields to Firestore doc. No action fields.
- **URL launching**: `url_launcher` is already a dependency. `external_url_helper.dart` has `launchExternalUrl()` which opens URLs externally. Already used in settings screen.
- **L10n**: `app_en.arb` and `app_bn.arb` need new strings.

## Implementation

### 1. Extend `AnnouncementModel` (`lib/models/announcement_model.dart`)
Add two nullable fields:
- `String? actionUrl` — the URL to open when button is tapped
- `String? actionLabel` — custom button text (falls back to a default like "Update" if null)

Update `fromDoc()` to parse these from Firestore. Update `const AnnouncementModel(...)` constructor.

### 2. Update Firestore mapper (`lib/features/admin/presentation/widgets/admin_announcement_helpers.dart`)
- Add `actionUrl` and `actionLabel` parameters to `announcementToFirestoreMap()`
- Use `_putOptionalField` for both (same pattern as `imageUrl`/`arabicText`)

### 3. Update Admin Form (`lib/features/admin/presentation/screens/admin_announcement_form_screen.dart`)
- Add `TextEditingController _actionUrlCtrl` and `_actionLabelCtrl`
- Initialize from `widget.existing` in `initState()`, dispose in `dispose()`
- Add two `AdminFormField` widgets in the form (after Image URL field):
  - "Action URL (optional)" — for the link
  - "Action Button Text (optional)" — for the label
- Pass both to `_buildDraft()` and `announcementToFirestoreMap()`

### 4. Update Announcement Modal (`lib/shared/widgets/announcement_modal.dart`)
- After the existing dismiss button, add a **conditional action button**:
  - Only shown when `announcement.actionUrl` is non-null and non-empty
  - Label uses `announcement.actionLabel` if set, otherwise defaults to l10n string
  - On tap: calls `launchExternalUrl(announcement.actionUrl!)` then `dismiss()`
  - Styled with a distinct look (outlined or different color) to differentiate from dismiss button
- When action button exists, the dismiss button stays as-is (users can still just dismiss)

### 5. Add L10n strings
**`app_en.arb`** (after `adminFormImageUrl`):
```json
"adminFormActionUrl": "Action URL (optional)",
"adminFormActionLabel": "Button Text (optional)",
"announcementActionDefault": "Open"
```

**`app_bn.arb`** (after `adminFormImageUrl`):
```json
"adminFormActionUrl": "অ্যাকশন URL (ঐচ্ছিক)",
"adminFormActionLabel": "বাটনের টেক্সট (ঐচ্ছিক)",
"announcementActionDefault": "খুলুন"
```

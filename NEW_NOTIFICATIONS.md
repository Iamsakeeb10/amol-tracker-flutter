## 10. Notification Tone Guidelines

Use this reference when writing new copy or A/B testing.

| Tone                  | Best for                       | Avoid when                            |
| --------------------- | ------------------------------ | ------------------------------------- |
| **Urgent**            | Evening reminders, streak loss | Morning, low-engagement users         |
| **Warm**              | Re-engagement, recovery        | Milestones, leaderboard context       |
| **Pride**             | Milestone, perfect score       | User had a bad week                   |
| **Islamic framing**   | Spiritual nudges, Jumu'ah      | Urgency messages (feels manipulative) |
| **Social**            | Afternoon nudges, leaderboard  | Users with low scores (embarrassing)  |
| **Personal/specific** | Missed amal reminders          | Generic broadcasts                    |

### Frequency rules

- Max **2 notifications per day** per user
- Always **cancel urgency reminders** if log is submitted
- **Never repeat** the same message text two days in a row
- Rotate spiritual copy — max **1 spiritual message per 3 days**
- Re-engagement flow: day 2 → warm, day 5 → gentle, day 10 → faith-based, day 14 → direct ask
- Social proof only works when **community is active** — don't send if count is below 5
